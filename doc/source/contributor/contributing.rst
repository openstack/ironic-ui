=================
How to Contribute
=================

Contributor Agreement
---------------------

OpenStack follows the Developer Certificate of Origin (DCO) for all code
contributions. Before submitting a change, please review the contribution
workflow in the OpenStack Contributor Guide:

   https://docs.openstack.org/contributors/

Project Hosting Details
-------------------------

Bug tracker
    https://bugs.launchpad.net/ironic-ui

Mailing list (prefix subjects with ``[ironic]`` for faster responses)
    http://lists.openstack.org/cgi-bin/mailman/listinfo/openstack-discuss

Code Hosting
    https://opendev.org/openstack/ironic-ui

Code Review
    https://review.opendev.org/#/q/status:open+project:openstack/ironic-ui,n,z
